# 🎮 Rock Paper Scissors

A simple command-line Rock Paper Scissors game built with Python.

The player competes against the computer by choosing Rock, Paper, or Scissors. The game keeps track of the player's score, the computer's score, and the number of ties.

## 📌 About the Project

This project was created as a beginner Python project to practice programming fundamentals and game logic.

The computer randomly selects Rock, Paper, or Scissors, while the player selects their choice. The program compares both choices and determines the winner.

## ✨ Features

* 🎮 Interactive command-line game
* 🤖 Computer opponent
* 🎲 Random computer choices
* 🪨 Rock option
* 📄 Paper option
* ✂️ Scissors option
* 🏆 Winner detection
* 📊 Score tracking
* 🤝 Tie tracking
* ❌ Invalid input handling
* 🚪 Quit option

## 🛠️ Technologies Used

* Python 3
* Python Random Module

## 🎯 Game Rules

The rules are:

```text
Rock beats Scissors
Scissors beats Paper
Paper beats Rock
```

If both the player and computer choose the same option, the round is a tie.

### Example

```text
Rock vs Scissors → Rock Wins
Scissors vs Paper → Scissors Wins
Paper vs Rock → Paper Wins
```

## 🎮 How to Play

When the game starts, you will see:

```text
1. Rock
2. Paper
3. Scissors
4. Quit
```

Enter:

```text
1
```

for Rock,

```text
2
```

for Paper,

or:

```text
3
```

for Scissors.

The computer will randomly select its choice.

The winner of the round will then be displayed.

## 📊 Score System

The game keeps track of:

* Player score
* Computer score
* Number of ties

Example:

```text
---------- SCORE ----------
You: 2
Computer: 1
Ties: 1
---------------------------
```
